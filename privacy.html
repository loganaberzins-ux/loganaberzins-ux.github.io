email-ops privacy policy

What it accesses

email-ops accesses Gmail with read-only access and, later, permission to change labels and to add its own summary messages to the owner’s mailbox. It does this only on the owner’s own Gmail accounts. It is not offered to other users.

Where data is kept

Data stays on the owner’s computer, except limited message content sent to the Anthropic API for optional AI classification when the owner enables it. No data is sold or shared.

AI classification

Optional AI classification uses the Anthropic API, and only if the owner enables it.

How to revoke access

Access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

email-ops’s use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
